# Трекер тренировок

Минималистичный трекер спортивных целей — одностраничное веб-приложение для телефона. Ставишь цель (например, 1000 отжиманий), отмечаешь подходы и следишь за прогрессом.

## Возможности

- **Онбординг без давления** — приложение начинается с чистого листа: сам выбираешь упражнения и цели, ничего не предустановлено
- **5 упражнений на выбор** — отжимания, приседания, планка (в секундах), подтягивания, пресс
- **Несколько целей одновременно** — экран «Обзор» показывает прогресс по всем упражнениям сразу
- **Быстрая запись подходов** — кнопки +/−, пресеты значений, цифровая клавиатура на телефоне
- **Статистика** — график за 14 дней, средний и лучший подход, дней с тренировками
- **История** — все подходы с датой и временем, ошибочные можно удалить
- **Напоминание о тренировке** — в заданное время покажет уведомление (пока страница открыта)
- **Тёмная тема** — тёплая «кофейная» палитра
- **100% офлайн** — один HTML-файл, без сервера, CDN и внешних скриптов; все данные хранятся в localStorage твоего браузера

## Как пользоваться

1. При первом запуске выбери упражнения и поставь цели (пресеты или своё значение)
2. После каждого подхода жми «Записать»
3. Следи за прогрессом на вкладках «Обзор» и «Статистика»
4. Добавить или убрать упражнение можно кнопкой «+» в полосе упражнений — записи при этом сохраняются
5. На телефоне: меню браузера → «Добавить на главный экран» — установится как приложение

## Резервная копия данных

Данные хранятся только в браузере. Чтобы не потерять их:

1. Открой приложение → F12 → Console
2. Введи: `copy(localStorage.pushup-tracker-v3)` — JSON скопируется в буфер обмена
3. Сохрани его в надёжное место

Восстановление: в консоли выполни

```js
localStorage.pushup-tracker-v3 = '<вставь сюда сохранённый JSON>';
```

и обнови страницу.
